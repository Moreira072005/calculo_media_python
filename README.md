##  Calculadora de média 

***Calculadora para identificar se o aluno foi aprovado ou reprovado.***

### Função do codigo:

 - Recebe duas notas via terminal 
 - Calcula a media aritmetica atraves de uma função dedicada  `calcular_media()` 
 - Exibe a media com formatação de 2 casas decimais devido a função `{media:2f}`
 - Verifica status: Aprovado (media>= 7.0) ou Reprovado

 - Python 3.14
